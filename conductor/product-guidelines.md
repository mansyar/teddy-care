# Product Guidelines — Teddy Care

## Brand
Warm, soft, safe. Rounded shapes, pastel palette, big touch targets (min
48px). Teddy's navy-outline cartoon style is the visual anchor — every screen
should feel like his world.

## Voice & Tone
- **To the child:** Teddy speaks in short, joyful bursts. Two-word sentences.
  Emoji-scale feelings, never paragraphs. *"Yummy!" "Splash!" "Night-night…"*
- **To the parent:** calm, plain, respectful. No jargon, no dark patterns, no
  guilt. Bedtime and mute are one tap away.
- **Never:** sarcasm, failure language ("wrong!", "you lost"), timers that
  shame, or any text a pre-reader must understand to play.

## UX Principles (ages 4+)
1. **Tap-first, zero reading.** Every action is an icon; every icon does
   something visible within 300ms.
2. **Mood is the UI.** Teddy's face + posture carry state; numbers stay in the
   parent panel.
3. **Forgiveness everywhere.** No lose states, no dead pets, no timers that
   punish. Neglect → sad face, never loss.
4. **Sound with an off-switch.** Music + SFX default on, parent mute persists,
   bedtime silences all.
5. **Offline honesty.** The game never pretends to need the network; install
   prompt only when it adds value.
6. **One thumb, any device.** 360px phone portrait is the design baseline;
   desktop is a bigger cozy window, not a different game.
